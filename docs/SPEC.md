Develop a Meridian Offline Commerce & Compliance Portal system for organizations that need to run internal auctions, manage controlled documents, and publish regulated communications without relying on any internet connectivity. The application supports four primary roles: Administrator (configures rules and data), Content Editor (authors listings, announcements, and documents), Reviewer/Approver (moderates content and approves workflows), and Participant (bids, searches products, completes trainings, and reads notices). Users sign in with a local username and password, then land on a React SPA workspace with a left navigation Drawer and a tabbed main area.

Key features include: Auction system with anti-sniping, proxy bidding, minimum increments, deposit wallet; Catalog with advanced search and moderation; Publishing Workbench with approval workflow and version rollback; Document & Archive with numbering, checkout, watermark and retention policies; Message Center with notifications and exportable queues.

Built as a pure React + TypeScript frontend SPA using IndexedDB for persistence, BroadcastChannel for cross-tab sync, Web Crypto for encryption, and PBKDF2 for passwords. Everything must work 100% offline.
